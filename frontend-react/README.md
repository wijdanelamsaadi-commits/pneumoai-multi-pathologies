# Interface React PneumoAI

Nouvelle interface web mock pour la détection multi-pathologies :
Pneumonie, Épanchement pleural, Consolidation et Normal.

## Lancer l'application

```bash
cd frontend-react
npm install
npm run dev
```

L'application démarre par défaut sur l'URL indiquée par Vite, généralement :

```text
http://localhost:5173
```

## Notes

- Cette étape ne contient aucune intégration IA ni backend.
- Les valeurs affichées sont fictives et codées en dur via `src/services/api.js`.
- L'ancien fichier Streamlit `frontend/app.py` n'est pas modifié.
